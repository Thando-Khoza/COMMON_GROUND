# COMMON GROUND
### Retail Data Quality & Investigative Analytics

## Overview

COMMON GROUND is an end-to-end data analytics project focused on investigating the quality, structure and reliability of retail transaction data.

Using the Online Retail II dataset, the project explores data inconsistencies, duplicate records, unusual transaction behaviour and operational exceptions through a series of structured investigations.

The project demonstrates how raw transactional data can be examined, validated, classified and transformed into meaningful analytical insights.

## Objectives

- Evaluate the quality and reliability of retail transaction data.
- Identify and investigate duplicates and data inconsistencies.
- Explore unusual transaction patterns and exceptions.
- Develop rule-based transaction classifications.
- Investigate operational and non-merchandise activity.
- Produce structured datasets and analytical findings.

## Dataset

**Online Retail II**

- Original records: 1,067,371
- Processed records: 1,044,848
- Period: December 2009 – December 2011
- Source: Two Excel worksheets

## Technologies

- Python
- Pandas
- OpenPyXL
- Matplotlib
- SQL concepts and structured data analysis

## Analytical Approach

The project follows a structured investigative process involving:

1. Data inspection and validation.
2. Data quality assessment.
3. Duplicate detection and investigation.
4. Transaction classification.
5. Operational and exception analysis.
6. Cross-sheet verification and analytical refinement.

## Key Results

- Processed and validated over one million transaction records.
- Identified and investigated missing values and duplicate patterns.
- Developed a transaction classification framework covering six categories.
- Classified all 1,044,848 processed records with no unclassified records.
- Conducted specialised investigations into operational, manual, postage and accounting-related transactions.

## Key Takeaway

COMMON GROUND demonstrates a practical approach to large-scale data investigation, combining Python programming, analytical reasoning and business-focused problem-solving to uncover patterns and assess data reliability.
